# AutomationExercise Login Automation

## Project Overview

This project automates the login functionality of the Automation Exercise website using Playwright and JavaScript.

The automation verifies that a registered user can successfully log in using valid credentials.

## Website

https://www.automationexercise.com/

## Technology Used

- Playwright
- JavaScript
- Node.js
- Git
- GitHub

## Test Scenario

1. Launch the Automation Exercise website.
2. Navigate to the Login page.
3. Enter the registered email address.
4. Enter the registered password.
5. Submit the login form.
6. Verify that the user is successfully logged in.
